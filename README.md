
# Sacrament Meeting Planner

A Next.js application for planning and managing sacrament meeting programs.

## Getting Started

First, install the dependencies:

```bash
npm install
```

Then start the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Project Purpose

The Sacrament Meeting Planner helps bishoprics and branch leaders organize and manage sacrament meeting programs, including:

- Meeting announcements
- Opening and closing hymns
- Prayers
- Ward and stake business
- Speakers and musical numbers

## Technologies

- Next.js
- React
- TypeScript
- Tailwind CSS
